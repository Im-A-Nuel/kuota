# Audit 001: frontend UI/UX (2026-10-06)

Scope: `frontend/` at commit `07bfa62` on `feat/frontend-ui`. Method: code read, production build, screenshots (desktop 1280, mobile 390, light and dark), and a headless keyboard/form probe.

Verified OK: no horizontal overflow at 390px, visible focus ring on every Tab stop including the amount radios, wallet dialog opens and closes with Escape, unknown mint shows the 404 page, both themes render.

Priority follows antislop tiers: HIGH = Hard Gate, MEDIUM = Purpose-Gate or a content gap against the docs, LOW = quality lock or polish.

## HIGH

1. **Wallet connect fails silently** (R-27, R-26). `WalletProvider` has no `onError`, and the dialog closes the moment a wallet is picked. A rejected or failed connection shows nothing. Fix: add `onError`, keep a "Connecting to Phantom" state, show the error in the dialog or a toast. `src/components/wallet-provider.tsx`, `src/components/wallet-dialog.tsx`.
2. **Launch form errors are hard to act on** (R-32). Probe: after an empty submit, focus stays where it was and five separate `role="alert"` messages fire at once. Fix: move focus to the first invalid field, keep one live summary, and drop `role="alert"` from the per-field messages.
3. **Launch preview shows wrong numbers on bad input** (R-38). Typing `150,000` marks the field invalid and the preview switches to "0% at the start, 0% at the end" and "n/a". Fix: accept thousands separators, and show "Fix the pricing fields to see the preview" instead of zeros.
4. **Sample figures contradict each other** (R-38). The curve marker uses the linear estimate (about 0.0058) while the voucher says 0.0061. The home voucher also says "Not launched" next to "On curve, 24%". Fix: derive the sample price from the same curve function, and make the home voucher say "Sample, not on-chain" instead of "Not launched".
5. **Ledgers ignore time and paging** (R-27, C-2). `createdAt` and `slot` are never rendered and `nextCursor` is dropped, so once real data arrives the rows have no time and only the first page shows. Fix: show relative time with the full timestamp in `title`, and add "Load older burns".
6. **Favicon is the Next.js default** (R-23). `src/app/favicon.ico` is the framework logo. Fix: an honest placeholder (a lowercase "k" in the display face) until a real logo is supplied.

## MEDIUM

7. **No path for agent developers** (C-3). Goal G-05 ("replace `fetch` with `kuotaFetch`") appears nowhere. Fix: a home section with the `createKuotaFetch` snippet and the decision rule from SCHEMA.md, labelled "not released yet".
8. **Provider setup stops at launch** (C-3, C-2). Nothing tells providers to add the kuota entry to `accepts` (`kuotaPaywall`) or to approve the burn delegate, and FR-06 needs that approval. Fix: an "After launch" checklist on `/launch` plus a provider panel on `/k/[mint]`.
9. **Two wallet prompts arrive unannounced.** Launch is build, sign `createConfig`, sign `createPoolWithFirstBuy`, then confirm, but the UI has one button. Fix: a step list that shows the current step and each step's transaction link.
10. **Network is hidden.** Devnet or mainnet only shows inside the wallet dialog, but mainnet proof is the whole point. Fix: a small network label in the header (a functional badge under R-09).
11. **Token page has no way to copy the mint.** Agents need the mint to configure a client. Fix: a copy button, a Solscan link for the mint, and a link to the endpoint.
12. **The graduated state is empty** (R-27). When `status = graduated` the chart disappears with nothing in its place, and there is no Jupiter link. Fix: a "Trading on DAMM v2" block with the pool and Jupiter links.
13. **The accent is spread too far** (Part 3 "one deliberate accent", R-29). Vermilion is used for CTAs, the discount badge, the curve marker, the redemption line, the focus ring, the active nav underline and error text, so errors and primary actions share a colour. Fix: keep the accent for buy, launch and the discount. Use ink for the focus ring and nav, a dashed ink line for the redemption price, and a separate error treatment (an icon with an outlined box).
14. **Ledger rows break on mobile** (R-03). The burn and payment rows use `flex-wrap`, so the stamp and transaction cells land on uneven second lines (see the 390px screenshot). Fix: a two-row grid with a fixed position for each cell.
15. **Voucher price sentence reads badly.** "per call now. ~~0.01~~ paying with USDC". Fix: "per call, vs 0.01 USDC paying direct".

## LOW

16. Hero CTAs stack at desktop with uneven widths. Put them in a row or give them equal widths.
17. No Open Graph image, and the token page title is only the symbol. The roadmap plans X threads with links, so add an OG image of the voucher per kuota.
18. No root `error.tsx` for home and launch. Only `/providers` and `/k/[mint]` have error boundaries.
19. The buy panel label "Difference" is vague. Use "You save compared with USDC".
20. The 402 code block and a future snippet have no copy button.
21. The chart has two y ticks and no label on the "now" marker. Add the current price next to the marker.
22. The UI is English only, while the community post is Indonesian. Language choice is the owner's call.
